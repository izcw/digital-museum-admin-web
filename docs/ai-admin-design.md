# AI 管理端交互与验收

本次仅修改 admin-web；不调用模型、不接入后端、不下发客户端。

## 数字人

- 基础资料、AI 配置、欢迎与异常话术、配置预演分组。
- 对话模型、多个知识库、已发布提示词的固定版本都从同一份前端数据选择。
- 每类事件可指定话术；未指定时按数字人专属、全局默认匹配。
- 保存只修改草稿。发布检查模型、知识库、提示词版本和全部必要话术。
- 发布保存配置及依赖快照，对比页分别展示快照和当前待发布内容。
- 历史快照可以查看、恢复为草稿；恢复后需要重新发布。
- 有历史版本的数字人可停用、归档、恢复，不删除历史。

## 模型、提示词、话术

- 模型区分对话/向量用途，按用途设置默认，列表展示引用与可用状态。
- 连接测试入口只解释当前预览限制，连接状态不会伪装成成功。
- 提示词自动提取双花括号变量，支持说明、必填、默认值、测试值、变量替换预演。
- 提示词发布生成递增版本，支持正文对比和恢复草稿。
- 话术按首次进入、无可靠资料、超时、断网、服务异常、敏感问题配置。
- 展示文本与播报文本分开，可配置后续动作；同范围同事件只允许一条启用话术。

## 知识资源

- 资源和目录按知识库隔离，状态与前端演示数据共用。
- 保留目录与文件拖拽、占位动画、宽度调节及目录展开记忆。
- 全部收起保留根目录；按名称/时间排序时关闭文件手工拖拽。
- 支持当前目录/全库搜索、定位路径、批量移动、撤销移动、批量标签、参与问答设置。
- 处理状态与参与问答分开。处理详情说明当前为模拟状态，可标记重试。
- 编辑/预览统一大弹窗。预览只读；取消编辑不改资源，未保存关闭有提示。
- 文本使用 Markdown；其他格式编辑说明而不是伪装编辑原文件。
- 本地文件选择、预览与记录可演示；二进制预览 URL 仅本次页面会话有效，刷新后提示重新选择。
- 标签与资源关联，重命名同步更新引用；标签不承担审核状态。

## 本地数据

使用 localStorage 的 museum-ai-admin-design-v1 键保存演示配置、资源记录和发布快照。API Key 不写入浏览器持久存储，不请求模型服务。浏览器不支持存储或超出配额时仅保留当前会话。

## 验证

- `node scripts/test-ai-admin.cjs`：发布校验、快照隔离、版本固定、恢复草稿、话术优先级、引用保护、知识库隔离、排除密钥的持久化。
- `npx vue-tsc --noEmit`：类型检查。
- 对本次修改的 Vue/TypeScript 文件运行 ESLint。
- `npx vite build`：生产构建。
- 另对资源管理组件函数验证根目录保留、文件排序/跨目录移动、目录排序及循环保护。

建议手工验收：在数字人中编辑并保存草稿 → 发布 V1 → 修改模型或话术 → 对比已发布与待发布 → 确认 V1 快照未改变 → 发布 V2 → 查看历史并恢复为草稿。再检查资源树收起后排序、不同知识库切换、Markdown 预览只读和取消编辑。当前浏览器自动化连接不可用，尚未进行页面视觉验收。

## 场景工作台重构（2026-09-15）

数字人列表入口现为 AI 应用工作台，导航标题在前端适配，未修改服务端菜单或客户端。

- 三个固定场景：首页综合问答、小小博物馆、央博知识库，共享数字人身份与音色。
- 场景分别绑定模型、知识库、固定提示词版本、讲解模板、授权来源、异常话术、会话与媒体策略。
- 原数字人页面保留在统一数字人页签的历史配置折叠区，旧数据不自动迁移成三个不同身份。
- 讲解内容支持文物 / 文化主题、出处、已知事实、推荐问题、Markdown 固定稿与资料确认；编辑和预览同尺寸。
- 知识资源保留原目录拖拽和编辑器，新增出处、关联对象和客户端展示 / 下载权限字段。
- 场景模型、知识库、提示词与异常话术参与原有引用保护。
- 发布保存独立快照并排除模型密钥；只纳入已确认讲解和已完成处理、参与问答的知识资源。分配仅记录目标版本，不伪造设备实际状态。
- 模拟器使用固定情境，不发出模型请求；同次访问可恢复各对象进度，新访客清空所有模拟会话。

### 当前边界

形象和音色为配置字段，尚未接入资产服务 / TTS。审核、外部搜索、知识索引版本、设备同步和正式会话服务均需后端接入。发布为本地配置快照，不是可分发的真实设备资源包。知识关联对象名称当前为前端字段，待藏品服务接入时换为稳定对象 ID。浏览器存储容量有限，工作台在存储失败时明确提示。

验证：scripts/test-ai-scenes.cjs 覆盖发布校验、引用保护、快照不变性、凭据排除与来源校验；原 scripts/test-ai-admin.cjs 继续运行。

### 多数字人选择修正

“统一”指同一个数字人跨场景保持身份、形象与音色一致，不限制数字人数量。数字人库支持新增、编辑、停用、删除，并可复用旧数字人资料；各场景分别配置可选数字人集合和默认项。被场景引用的数字人禁止直接删除或停用。预览中可以选择数字人，跨场景优先保留原选择，不可用时采用目标场景默认项；切换数字人不清空对象会话。发布快照固定所引用的多个数字人配置。原单身份草稿及旧版本恢复会迁移为数字人集合，旧发布记录本身保持不变。

### 数字人按学校发布

数字人编辑始终修改草稿，需单独发布后才出现在客户端模拟候选中。发布范围支持全部学校（含后续新增学校）或指定学校多选；候选复用已有学校接口，只读取真实学校列表。每次发布固定形象、角色、音色与版本说明。学校专属版本优先于通用版本，通用更新不覆盖专属定制；撤回当前匹配版本后不自动回退旧版或通用版，需重新发布。旧草稿迁移不自动开放。场景发布也必须引用已有数字人发布记录，不能绕过数字人发布。预览按学校读取发布快照，不读取数字人草稿。真实客户端学校鉴权与下发尚未接入，本次没有修改后端或客户端。

### 数字人列表管理入口

页面主体调整为可搜索、按发布状态筛选的数字人表格，展示名称、角色、音色、场景、学校开放范围、草稿更新提示与最近版本。新增和编辑均在独立草稿弹窗中进行，保存不等于发布；每行提供发布 / 版本和删除入口。场景、讲解、安全、模拟及场景版本管理保留在“应用与讲解配置”弹窗中。

### 每个数字人独立配置及发布

列表每行提供“配置”入口，独立保存三个场景的模型、知识库、提示词版本、异常话术、会话参数，以及讲解模板、内容和授权来源。旧共享配置作为初始副本，修改后互不影响。发布以单个数字人为单位，版本固定形象、音色、独立配置及模型 / 提示词 / 话术引用快照，并继续支持全部学校或指定学校。列表的草稿更新提示同时比较身份和独立配置。原全局场景发布入口从本页面移除，保留旧数据兼容。

### 默认组件与头像

数字人列表参照 /system/user 重构，复用 ArtSearchBar、ArtTableHeader、ArtTable、useTableColumns、ArtButtonTable、ElForm / FormRules、ElAvatar 和 ElUpload。支持查询 / 重置、分页、列配置、默认表格密度与刷新。数字人头像与姓名同列展示，资料表单支持预设头像、上传 PNG / JPG / WebP（512 KB 内）及恢复默认；旧数字人补默认头像，历史发布快照不被草稿头像修改影响。上传只在本地读取，不向后台写入文件。浏览器连接工具不可用，未执行视觉与点击验收。

### 配置简化与弹窗定位

独立配置弹窗使用 align-center 和受视口限制的固定高度，正文内部滚动。配置收敛为回答设置、讲解内容、预览与发布三个页签。回答设置直接展示使用位置、知识库、模型、展示方式和打断讲解；话术、记忆与外部来源收进默认折叠的更多设置，讲解顺序模板也默认折叠。每次打开回到回答设置。数字人列表操作使用文字按钮。
