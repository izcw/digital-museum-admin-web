# AI 管理端交互与验收

本次仅修改 admin-web；不调用模型、不接入后端、不下发客户端。

## 数字人

- 基础资料、AI 配置、欢迎与异常话术、配置预演分组。
- 对话模型、多个知识库、已发布提示词的固定版本都从同一份前端数据选择。
- 每类事件可指定话术；未指定时按数字人专属、全局默认匹配。
- 保存只修改草稿。发布检查模型、知识库、提示词版本和全部必要话术。
- 发布保存配置及依赖快照，对比页分别展示快照和当前待发布内容。
- 历史快照可以查看、恢复为草稿；恢复后需要重新发布。
- 有历史版本的数字人可停用、归档、恢复，不删除历史。

## 模型、提示词、话术

- 模型区分对话/向量用途，按用途设置默认，列表展示引用与可用状态。
- 连接测试入口只解释当前预览限制，连接状态不会伪装成成功。
- 提示词自动提取双花括号变量，支持说明、必填、默认值、测试值、变量替换预演。
- 提示词发布生成递增版本，支持正文对比和恢复草稿。
- 话术按首次进入、无可靠资料、超时、断网、服务异常、敏感问题配置。
- 展示文本与播报文本分开，可配置后续动作；同范围同事件只允许一条启用话术。

## 知识资源

- 资源和目录按知识库隔离，状态与前端演示数据共用。
- 保留目录与文件拖拽、占位动画、宽度调节及目录展开记忆。
- 全部收起保留根目录；按名称/时间排序时关闭文件手工拖拽。
- 支持当前目录/全库搜索、定位路径、批量移动、撤销移动、批量标签、参与问答设置。
- 处理状态与参与问答分开。处理详情说明当前为模拟状态，可标记重试。
- 编辑/预览统一大弹窗。预览只读；取消编辑不改资源，未保存关闭有提示。
- 文本使用 Markdown；其他格式编辑说明而不是伪装编辑原文件。
- 本地文件选择、预览与记录可演示；二进制预览 URL 仅本次页面会话有效，刷新后提示重新选择。
- 标签与资源关联，重命名同步更新引用；标签不承担审核状态。

## 本地数据

使用 localStorage 的 museum-ai-admin-design-v1 键保存演示配置、资源记录和发布快照。API Key 不写入浏览器持久存储，不请求模型服务。浏览器不支持存储或超出配额时仅保留当前会话。

## 验证

- `node scripts/test-ai-admin.cjs`：发布校验、快照隔离、版本固定、恢复草稿、话术优先级、引用保护、知识库隔离、排除密钥的持久化。
- `npx vue-tsc --noEmit`：类型检查。
- 对本次修改的 Vue/TypeScript 文件运行 ESLint。
- `npx vite build`：生产构建。
- 另对资源管理组件函数验证根目录保留、文件排序/跨目录移动、目录排序及循环保护。

建议手工验收：在数字人中编辑并保存草稿 → 发布 V1 → 修改模型或话术 → 对比已发布与待发布 → 确认 V1 快照未改变 → 发布 V2 → 查看历史并恢复为草稿。再检查资源树收起后排序、不同知识库切换、Markdown 预览只读和取消编辑。当前浏览器自动化连接不可用，尚未进行页面视觉验收。
